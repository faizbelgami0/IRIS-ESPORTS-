IRIS ESPORTS — recovered website package

OPEN LOCALLY:
- Keep the complete folder structure.
- For best results, run a local web server from this folder (for example: python -m http.server 8000)
- Open http://localhost:8000

GITHUB PAGES:
- Upload the CONTENTS of this folder to the root of a GitHub repository.
- In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
- Wait for deployment and open the Pages URL.

Notes:
- The original seven-page React website and its local supporting files are included.
- Google Fonts may still load from Google; local fallback fonts are defined by the stylesheet.
- Contact links/forms and any third-party integrations should be tested after publishing.
